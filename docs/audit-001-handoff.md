## Railway redeploy still uncertain

At session end, we noticed Railway did NOT auto-redeploy on a merge to
`main` (the model sweep commit `35d648f` may or may not be running on
the live service). Until you verify this:

1. Railway dashboard → backend service → **Deployments** tab.
2. Find the most recent deploy. Click into it. Note the commit SHA.
3. If it's `35d648f` or later, the model fix is deployed.
4. If it's older, click **Redeploy** on the most recent deploy entry.
   This forces a fresh build from `main`.
5. Check **Settings → Source → Branch** is set to `main` and that
   **Auto Deploys** is enabled.

Until Railway is on a build with the timezone=True sweep, sync will
keep failing with `can't subtract offset-naive and offset-aware
datetimes` errors.

## How to verify everything once it's settled

After all four PRs are merged AND Railway is confirmed redeployed,
run this sequence:

```bash
# 1. Confirm DB schema is sane.
python scripts/diagnose_railway.py | tee docs/audit-001-findings.md

# Expected (compared to last snapshot):
# - "Primary-key autoincrement check": all 14 tables OK
# - "Tables present in schema": no MISSING warnings (RC3 fixed)
# - "oauth_tokens": both strava AND whoop rows, both with valid expires_at
# - "sync_log": new rows from today
# - "Data freshness": activities/sleep moved forward from 2026-04-28

# 2. Trigger a real sync.
echo '{"source": "all"}' > /tmp/sync-trigger.json
curl -X POST https://health-tracker-consolidated.up.railway.app/api/sync/trigger \
  -H "Content-Type: application/json" \
  --data @/tmp/sync-trigger.json

# Expected: mostly success states; possibly Whoop weather/elevation
# may still show small errors depending on edge cases.
```

Then in a browser:
- `https://health-tracker-consolidated.up.railway.app/record`
- Log a single set, hit Finish
- DevTools Network → `POST /api/strength/sets` should return 201

If all of that passes, **Bugs A and B are fully closed.**

Commit the post-fix `docs/audit-001-findings.md` snapshot to capture
the green state.

  Audit-001-plan.md has the full brief.

  dialect-guard `/api/sync/debug/db`, fix sync hint message, dedupe
  `.env.example`.

  `oauth_tokens` table to match Strava/Whoop pattern (currently relies
  on `.env` which doesn't exist on Railway).
- **W1-deploy-cleanup**: quarantine the legacy `deploy/` Mac-mini
  artifacts.

  even on Postgres; move to JSONB.

  Railway ever auto-scales, two schedulers run.

These can be tackled in a future agent wave. The four PRs already in
flight cover the most urgent items.
